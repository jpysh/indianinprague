# Everything here is public and meant to be found — by search engines and by AI
# assistants alike. There is no admin area, no user content and no paywall, so there is
# nothing to disallow.
#
# Content signals (the Cloudflare/IETF convention, honoured by a growing number of
# crawlers) state the intent explicitly rather than leaving it to be inferred:
#
#   search    = yes  — index this and return it in search results
#   ai-input  = yes  — ground AI answers on it and cite it (this is the one that decides
#                      whether the site can show up inside ChatGPT / Claude / Perplexity
#                      answers, which is what "appearing in AI search" actually means)
#   ai-train  = yes  — train and fine-tune models on it
#
# ai-train is the only one of the three that is effectively one-way: content already
# absorbed into a trained model cannot be withdrawn later. Set here to yes deliberately.

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=yes
Allow: /
